# DesafioReconhecimentoFacial
Repositório destinado às anotações do Desafio de Projeto Reconhecimento Facial e transformação de imagens em Dados no Azure ML, da DIO.

Vision Studio - Faces
Identifica rostos nas imagens
É possível usar imagens da plataforma ou realizar o upload, automaticamente mostra os atributos e gera um JSON

Vision Studio - Extract text from images
Identifica caracteres nas imagens
É possível usar imagens da plataforma ou realizar o upload, automaticamente mostra os atributos e gera um JSON

Vision Studio - Add captions to images
Cria legenda para a imagem
É possível usar imagens da plataforma ou realizar o upload, automaticamente gera a legenda e um JSON
